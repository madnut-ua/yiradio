Flasher

yiRadio onto an ESP32-S3 from the browser: firmware for your display and your wiring, with no ESP-IDF to install.

This browser cannot use a serial port. Open the page in Chrome or Edge on a computer - phones, Firefox and Safari cannot flash.

Wiring

Edit

    1. Firmware

    The program and the wiring. Wi-Fi, settings, the playlist and station icons stay as they are - this is the button for updates.

    Erasing removes the file system too: write it afterwards with the button below.

    Since version 1.6.1 the radio's memory is laid out differently, and this board has the old layout. After writing, the settings, the Wi-Fi networks, the stations and their pictures on the radio will not be kept. If the radio works, first download a backup in its web interface (Settings → Backup) and an export of the stations (Stations → Export). The flasher writes the firmware and the file system; then restore the backup and the stations.

    2. File system

    The web interface and the initial settings. Needed on a first install - without it the radio has no web pages - and when a new version changes the web interface.

    Writing it erases the saved Wi-Fi networks, the settings, the playlist and the station icons. On a working radio take a backup first (Settings - Backup) and restore it afterwards.

    3. Wi-Fi

    Connect the radio to your home network over the same cable - no access point, no phone. The password goes to the board only and is kept nowhere on this page. Works for a radio flashed earlier too, if its version has this feature.

    Progress

    Connect the board to the computer by its UART port and press one of the buttons.
